# СРО №1: Restaurant Order System

Индивидуальный мини-проект по дисциплине «Визуальное программирование» (Вариант №8).

## Описание проекта
Настольное приложение на JavaFX для автоматизации заказа блюд в ресторане. Программа позволяет:
* Просматривать каталог меню (с разделением по категориям и ценам).
* Искать блюда по названию или категории.
* Добавлять позиции в заказ, изменять их количество и рассчитывать итоговую стоимость.
* Добавлять новые блюда через отдельную форму (второе окно).
* Проходить валидацию ввода с выводом ошибок через диалоговые окна (`Alert`).

## Технологии
* Java 17+
* JavaFX
* FXML & Scene Builder
* Maven

## Инструкция по запуску
1. Клонируйте репозиторий или скачайте архив проекта.
2. Откройте проект в **IntelliJ IDEA** как Maven-проект.
3. Дождитесь загрузки зависимостей.
4. Запустите приложение через класс `app.Main`.
